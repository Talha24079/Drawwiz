# Drawwiz Project Files

## What Each File Does

### Backend (Server)
- `server.js` - Main server, handles connections
- `roomManager.js` - Creates/manages rooms
- `gameManager.js` - Game logic & scoring
- `wordList.js` - Words for drawing

### Frontend Pages
- `Home.jsx` - Landing page
- `Room.jsx` - Game room

### Frontend Components (UI)
- `Canvas.jsx` - Drawing board
- `Leaderboard.jsx` - Score rankings
- `Chat.jsx` - Messages
- `Timer.jsx` - Countdown
- `WordSelector.jsx` - Word picker

### Frontend Logic  
- `useSocket.js` - Server connection
- `useDrawing.js` - Drawing logic

### Frontend Utils
- `canvasRenderer.js` - Canvas helpers

That's it! Simple and organized.
