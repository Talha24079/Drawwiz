# Drawwiz - Quick Start Guide

## Installation & Setup

### Step 1: Install Backend Dependencies
```bash
cd backend
npm install
```

### Step 2: Install Frontend Dependencies
```bash
cd frontend
npm install
```

## Running the Application

### Terminal 1: Backend
```bash
cd backend
npm start
```
✓ Server running on http://localhost:3001

### Terminal 2: Frontend
```bash
cd frontend
npm run dev
```
✓ App running on http://localhost:5173

## Open in Browser
Navigate to: **http://localhost:5173**

## First Game
1. Enter your name
2. Click "Create New Room"
3. Share the room URL with friends
4. Start the game and have fun!

---

**Note**: You need Node.js installed on your system. If you don't have it, download from https://nodejs.org/
